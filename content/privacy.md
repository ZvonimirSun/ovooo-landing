OVOOO 统一身份认证服务为 OVOOO 及其相关应用提供统一的账户管理、身份验证和单点登录（SSO）功能。

用户可以通过受支持的第三方身份提供商登录统一身份认证服务，并在获得授权后使用同一账户访问接入该认证系统的相关应用。

本隐私权政策说明 OVOOO 统一身份认证服务在进行第三方登录、账户关联和单点登录过程中如何收集、使用、存储和保护相关信息。

## 1. 身份认证服务

OVOOO 使用统一身份认证系统集中管理用户身份。接入该系统的应用可以通过标准身份认证协议确认用户身份，从而实现单点登录，无需用户在每个应用中重复创建独立账户。

目前，统一身份认证服务可能支持以下第三方身份提供商：

- Google；
- GitHub；
- Linux DO；
- 未来可能增加的其他身份认证服务。

不同身份提供商可能使用 OAuth2、OpenID Connect 或其他标准身份认证协议。

## 2. 我们收集的信息

当您使用第三方账号登录 OVOOO 统一身份认证服务时，我们可能根据相应身份提供商实际提供的授权范围获取以下信息中的部分或全部：

- 第三方平台提供的用户唯一标识符；
- 用户名、昵称或显示名称；
- 电子邮件地址；
- 头像；
- 用于完成身份认证所必要的其他基础账户信息。

这些信息主要用于识别您的身份、创建或关联统一账户，以及向接入 OVOOO 统一身份认证服务的应用提供登录能力。

我们仅使用身份提供商正常身份认证流程所提供的授权范围，不会为了统一登录功能主动申请与身份认证无关的额外访问权限。

### Google 登录

使用 Google 登录时，身份认证通常基于 `openid`、`email` 和 `profile` 等基础身份信息。

我们可能获取您的 Google 用户唯一标识符、姓名、电子邮件地址和头像等基础账户信息。

我们不会因使用 Google 登录而访问您的 Gmail 邮件、Google Drive 文件、Google 联系人、Google 日历或其他与身份认证无关的 Google 服务数据。

### GitHub 登录

使用 GitHub 登录时，我们可能通过 GitHub 提供的默认身份认证流程获取用于识别账户的基础资料，例如：

- GitHub 用户 ID；
- 用户名或显示名称；
- 头像；
- GitHub 在授权范围内提供的电子邮件地址。

我们不会因使用 GitHub 登录而访问您的私人代码仓库、组织内部资源、Issues、Pull Requests 或其他与身份认证无关的 GitHub 内容。

### Linux DO 登录

使用 Linux DO 登录时，我们可能通过其提供的 OAuth2 身份认证服务获取用于识别用户身份的基础账户信息，例如用户唯一标识符、用户名、显示名称、头像或授权接口提供的其他基础身份信息。

获取的信息仅用于统一身份认证、账户关联和单点登录。

## 3. 信息的使用方式

OVOOO 统一身份认证服务获取的账户和身份信息主要用于：

- 验证您的身份；
- 创建和管理统一身份认证账户；
- 将第三方账号与统一账户进行关联；
- 向接入认证系统的应用提供单点登录（SSO）功能；
- 向相关应用提供完成身份识别所必要的账户信息；
- 维护登录状态和认证会话；
- 防止账号盗用、滥用和未经授权的访问；
- 维护身份认证服务的稳定性与安全性。

我们不会出售通过身份认证服务获取的个人信息，也不会将这些信息用于第三方广告投放。

## 4. 单点登录与信息共享

当您通过 OVOOO 统一身份认证服务登录某个接入应用时，认证系统可能向该应用提供完成身份认证所必要的信息。

这些信息通常可能包括：

- 用于区分用户的唯一标识符；
- 用户名或显示名称；
- 电子邮件地址；
- 头像；
- 该应用完成身份认证所需要的其他基础身份信息。

接入应用不会因此直接获得您的第三方平台账号密码。

除以下情况外，我们不会向无关第三方出售、出租或披露您的个人信息：

- 为提供您主动使用的统一身份认证或相关应用服务所必需；
- 经您明确授权；
- 根据适用法律法规、司法机关或政府机构的合法要求；
- 为保护用户、服务或其他人的合法权益和安全所必需。

## 5. 信息存储与安全

为持续提供统一身份认证和账户关联功能，我们可能在身份认证系统中保存必要的账户和身份信息。

我们会采取合理的技术和管理措施保护相关信息，包括但不限于访问控制、身份验证、权限管理、加密传输以及必要的安全日志记录。

我们仅在提供身份认证服务、保障系统安全、处理争议或满足法律要求所必要的期限内保存相关信息。

## 6. 第三方身份提供商

当您选择 Google、GitHub、Linux DO 或其他第三方账号登录时，身份验证过程通常会由相应第三方平台完成。

OVOOO 统一身份认证服务不会获取或保存您在第三方身份提供商处使用的账户密码。

第三方身份提供商对相关信息的收集、处理和保护，同时受其自身隐私政策、服务条款以及相关规则约束。

您通常可以通过相应第三方平台提供的账户或授权管理功能，查看或撤销授予 OVOOO 统一身份认证服务的授权。

## 7. 您的权利

您可以停止使用第三方账号登录，或通过相应身份提供商撤销已经授予的 OAuth 或 OpenID Connect 授权。

撤销第三方身份提供商的授权不会自动删除已经在 OVOOO 统一身份认证服务中创建的账户。

如需查询、更正或删除与统一身份认证服务相关的个人账户信息，您可以通过本站提供的联系方式与我们联系。

删除账户后，除法律法规、安全审计、防止滥用或其他合理需要要求保留的信息外，我们将删除或匿名化与该账户相关的个人信息。

## 8. 未成年人

OVOOO 统一身份认证服务并非专门面向儿童设计。

如果适用法律要求未成年人使用相关服务时取得监护人同意，应在获得相应授权后使用。

## 9. 隐私权政策的更新

我们可能根据统一身份认证服务的功能变化、新增身份提供商、相关应用接入情况、法律法规或第三方平台要求更新本隐私权政策。

更新后的版本将在本页面公布，并通过页面顶部的“最后更新日期”标识最新版本。

## 10. 联系方式

如您对本隐私权政策、统一身份认证服务或个人信息处理方式有疑问，可以通过 OVOOO 网站提供的联系方式与我们联系。
